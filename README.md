# email

Empiria Lab's former email guide and signatures (GitHub Pages, https://empiria-lab.github.io/email/).

**Moved on 3 November 2026 to https://email.empirialab.cl**, built from the `empiria-email` repository. Every page of this site now redirects there: the guide to the homepage and each signature page to the signature builder at https://email.empirialab.cl/firmas. This repository is archived.

**Keep `docs/images/` and don't rename or delete this repository.** Signatures installed before the move load their logo from `https://raw.githubusercontent.com/Empiria-Lab/signatures/refs/heads/main/docs/images/Empiria.png` (`Empiria-Lab/signatures` is this repository's former name, which GitHub redirects here), and the Fiestas Patrias and Navidad variants live beside it.
